# 初期セットアップの手順

このリポは [repo-setup-template](https://github.com/dhc4mens/repo-setup-template) から作った。初期セットアップ・ラベル・pre-commit・Claude Code のプロジェクト設定などの手順の正本は、テンプレートの [docs/SETUP.md](https://github.com/dhc4mens/repo-setup-template/blob/main/docs/SETUP.md)。

展開した時にここへコピーした写しは、テンプレートの更新に追随せずに古くなっていた（廃止済みのラベル `status/wip`、`.claude/settings.json` に model を置く案内など）ので、案内だけにした（dotfiles#344）。
